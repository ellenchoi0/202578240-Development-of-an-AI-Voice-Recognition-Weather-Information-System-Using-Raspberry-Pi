# Development of an AI Voice Recognition Weather Information System Using Raspberry Pi

라즈베리파이에 마이크와 스피커를 연동하여 사용자의 음성 명령을 인식하고, 오픈 API로 수집한 실시간 기상 정보를 한글 음성(TTS)으로 안내하는 스마트 장치 개발 프로젝트입니다.

> 본 프로젝트는 리눅스 환경에서의 한글 텍스트 깨짐 및 입력 문제를 해결하기 위해 fcitx5와 한글 폰트를 설정하고,
> SpeechRecognition 및 espeak를 통합하여 인간-컴퓨터 상호작용(HCI) 환경을 구축하는 과정을 다룹니다.

## 개요

USB 마이크와 오디오 출력 장치를 활용해 특정 키워드("날씨")를 감지하는 인공지능 음성 인식 장치를 구현합니다. 기상청 데이터를 가져오는 웹 데이터 파싱 기술을 익히고, 구글 음성 인식 엔진 및 리눅스 백그라운드 자동 시작 설정을 직접 수행하여 실시간으로 날씨 정보를 응답하는 양방향 임베디드 시스템을 학습합니다.

## 핵심 특징

- **실시간 음성 인식**: Google Speech Recognition API를 활용한 마이크 입력 스트림의 텍스트 변환
- **동적 데이터 파싱**: 기상청 RSS 데이터를 가공하여 현재 기온과 습도 정보를 실시간 추출
- **한글 특화 TTS**: espeak 한국어 옵션(-v ko+f5)을 활용한 부드러운 한글 문장 낭독 구현
- **리눅스 한글 최적화**: fcitx5 한글 입력기 및 ~/.bashrc 환경 변수 설정을 통한 시스템 다국어 지원

## 하드웨어 아키텍처

본 프로젝트는 라즈베리파이 4 하드웨어를 중심으로 입력 장치(마이크)와 출력 장치(스피커)를 기반으 설계되었습니다.

## 시스템 구성 및 통신 이론

- **음성 인식 인터페이스**: SpeechRecognition 모듈을 사용하여 캡처된 오디오 프레임을 서버로 전송 후 형태소 판별
- **한글 환경 구성**: fcitx5 입력기 프레임워크와 fonts-unfonts-core 패키지를 연동하여 글자 깨짐 방지
- **부팅 자동화**: ~/.config/autostart/ 경로 내 데스크톱 엔트리(.desktop) 설정을 통해 백그라운드 프로세스 자동 상주 구현

## 실행 및 설치

### 1. 한글 및 TTS 필수 패키지 설치

터미널 창을 열고 라즈베리파이 운영체제 레이어에 아래 패키지들을 순차적으로 설치합니다.
> sudo apt-get install espeak -y                 # TTS(Text-to-Speech) 프로그램 설치
> sudo apt install -y fonts-unfonts-core         # 깨짐 방지용 한글 폰트 설치
> sudo apt install -y fcitx5 fcitx5-hangul fcitx5-config-qt  # fcitx5 한글 입력기 설치

### 2. 환경 변수 등록 및 자동 시작 설정

터미널 및 시스템 전반에서 한글 입력 인터페이스가 연동되도록 설정을 추가합니다.
- 환경 변수 추가: nano ~/.bashrc 명령어로 파일을 열고 맨 하단에'export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx' 코드를 추가합니다.
- 백그라운드 자동 시작 설정: 재부팅 시 수동으로 켜야 하는 번거로움을 없애기 위해 자동 시작 파일을 생성합니다.
- 생성된 fcitx5.desktop 파일에 자동 실행 구문을 적어 저장한 뒤 sudo reboot 명령어로 시스템을 재시작하여 설정을 완전히 동기화합니다.


### 3. 프로젝트 실행
- 가상환경 활성화 후 소스코드가 있는 디렉토리에서 메인 프로그램을 구동합니다.

## 주요 이슈 해결
- 가상환경 내 한글 입력 및 표시 오류: 영문 베이스인 라즈베리파이 OS의 뼈대가 되는 ~/.bashrc 환경 변수 구조를 수동 매핑하고, 자동 실행 엔트리를 빌드하여 에디터와 터미널 창에서 한글이 네모 모양으로 깨지지 않고 매끄럽게 입력되도록 해결함.
- 오디오 처리 흐름과 네트워크 레이턴시: 마이크 입력 후 구글 클라우드 서버를 거쳐 텍스트로 치환되는 과정에서 발생하는 일시적인 시간 차이(Latency)를 확인하였으며, 터미널 로그 분석을 통해 데이터가 바인딩되는 동작 흐름을 추적함.
- 예외 처리 구문을 통한 시스템 안정화: 음성 입력이 없거나 무음일 때 생기는 오류(UnknownValueError), 인터넷 연결 불안정으로 발생하는 에러(RequestError)들을 try-except 예외 복구 장치로 방어함. 이를 통해 에러 발생 시에도 프로그램이 다운되지 않고 지속해서 다음 마이크 프레임을 대기하도록 설계함.
